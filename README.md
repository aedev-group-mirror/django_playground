# django_playground playground 0.3.1

django_playground is a Python multi-platform playground project based on the [__Kivy__ Framework](https://kivy.org) 
and some portions of the [__ae__ namespace(Application Environment)](https://ae.readthedocs.io "ae on rtd").

the source code is available at [Gitlab](https://gitlab.com/django_playground-group/django_playground)
maintained by the user group django_playground-group.
